# Coordination retrospective at M2

Evidence is file use and actual commands, not agent consensus.

- Upstream worker's pinned sources and docs/upstream.md were used by coordinator to build compatibility/src/main.rs and retain upstream license, and by the tools worker to implement current write/bash input names and classify deviations. Context-hook findings corrected the premise that Pi has no context editing.
- Verifier's experiments/truncate-cases.json and original-module oracle were consumed by coordinator's Rust probe and compare-truncate.mjs: 36 full result comparisons. That is an integrated artifact dependency, not parallel reports saying the same thing.
- Runtime worker's src/lib.rs/main.rs were exercised by independent experiments/verify-runtime.py through actual CLI processes. Coordinator found FIFO blocking and worker added a regression. Coordinator's strict clippy found two style issues and fixed them before M1 commit.
- Extension worker's Node sidecar was executed by coordinator and baseline verifier, but was not used by the Rust runtime. It is a tested prototype, not delivered extension support. Prior extension-first next-step priority did not address inability to modify/test a repository; M2 prioritizes that observed usability gap.
- M1 reports overstated perceived maturity with “runnable version”; user asked whether core had already been rewritten. Subsequent report clarified minimal runtime vs Pi replacement. Future milestone reports must name working scenario and unimplemented user-visible behaviors, not just pass counts.
- User intervention: initial request established goals; user clarified empty project, asked maturity, authorized GitHub creation/push, and explicitly steered next iteration to independent verification and coding usability. Ordinary implementation fixes needed no user signoff. This is not evidence of fully autonomous project selection yet.
- M2 baseline was rerun both locally and by clean-checkout verifier. Local rerun is integration smoke; independent clean checkout is reproducibility evidence. Future avoid duplicating the entire baseline repeatedly without changes. Clean-checkout verifier remains separate from implementer for final acceptance.
- M2 tool tests initially could not compile because `pub mod tools` had not been integrated. Worker communicated dependency, session owner added module, then five real tool tests passed. Explicit file ownership worked; no merge conflicts observed. Keep ownership plus an agreed function signature; no need for a new coordination service.
- M2 delegation hit agent thread-count limit when creating a fresh session worker; reused prior runtime worker. Then all three workers hit account usage limit. The tools worker had left untracked source, the verifier had sent partial command evidence, and the session worker had no changes. Heartbeat messages arrived during outage but no completed coding milestone resulted. Resumed the same workers and inspected partial files; do not erase partial work or infer completion from a scheduled wakeup.

Mechanism change grounded in these failures: store frozen acceptance before integration, distinguish partial vs completed artifacts, and reuse existing worker handles when creation limits are reached. On quota outage retain checkpoint and stop retrying identical dispatches until external state changes. Keep max four simultaneous agents including coordinator. No orchestration platform added. Usage counters remain unavailable through native worker tools; record unknown rather than zero.

Coordinator's new public demo caught a further integration failure: a rapid same-size Python source rewrite left a timestamp-based bytecode cache, so the first post-fix test still failed despite correct file bytes; the demo's output assertion failed rather than accepting scripted success text. All demo Python invocations now use `-B` in fresh repositories. The independent verifier already sets PYTHONDONTWRITEBYTECODE=1. This is a reproducibility-fixture correction, not removal of the passing-test requirement. Strict clippy also found a nested-if style issue in tools; coordinator collapsed it and reran the check.
