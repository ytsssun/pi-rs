# Catalog reproducibility: input replay foundation

## Current evidence

Fork CI run `35322988782` at foundation head `34b2aaf63` built successfully but
failed TypeScript checking after generating live model catalogs. The generator
fetches models.dev, OpenRouter, Vercel AI Gateway, and NVIDIA model lists. Its
JSON output is ignored by Git, and TypeScript model IDs derive from that JSON.
Consequently the same source commit can acquire different types over time.

The earlier claim that this was a static baseline error or caused by local
Node 22.18 is superseded. The local check initially lacked generated JSON;
CI generated current JSON and encountered different failures. Neither result
proves a Rust regression.

An existing September 8 generated snapshot from the earlier prototype validates
its manifest but does not match newer fork expectations (DeepSeek model IDs and
API groupings). Replacing live data with that snapshot is therefore insufficient.
Do not weaken assertions or manufacture missing catalog metadata to make it pass.

## Implemented bounded step

`scripts/model-catalog-replay-preload.mjs` replaces generator fetch with a strict
local replay. All JSON bodies are checksum-verified before use. Missing URLs,
duplicate URLs, changed bytes, and paths outside the snapshot fail. There is no
network fallback. This is build tooling, not a provider runtime change.

```sh
node --test scripts/model-catalog-replay.test.mjs
PI_MODEL_CATALOG_SNAPSHOT=/absolute/path/manifest.json \
  node --import ./scripts/model-catalog-replay-preload.mjs \
  packages/ai/scripts/generate-models.ts --strict --data-only
npm run build:offline
```

Manifest format:

```json
{
  "schemaVersion": 1,
  "responses": [
    {
      "url": "https://models.dev/api.json",
      "file": "models-dev.json",
      "sha256": "SHA256_OF_EXACT_RESPONSE_BYTES"
    }
  ]
}
```

Required source URLs for a full snapshot are:

- `https://models.dev/api.json`
- `https://openrouter.ai/api/v1/models`
- `https://ai-gateway.vercel.sh/v1/models`
- `https://integrate.api.nvidia.com/v1/models` (when NVIDIA appears in models.dev)

## Remaining repair and acceptance

1. Capture these public responses together; record capture time, URLs, body
   hashes, generator commit, and model-data manifest. Never record credentials.
2. Reconcile each existing test against that explicit snapshot: preserve protocol
   assertions using independent synthetic model fixtures where the test concerns
   request behavior, and review intentional catalog assertions separately.
3. Generate twice in clean checkouts using replay, with network unavailable;
   compare all generated bytes except the generator's timestamp field.
4. Change CI to replay plus `build:offline`; retain every check and test.
5. Make catalog refresh a separately reviewed operation with before/after diff.

This PR provides the strict replay mechanism and regression tests only. It does
not yet contain an approved full catalog snapshot, switch product CI offline,
or resolve the existing catalog/test failures. Full CI must be green before
merging the Rust foundation; replay tests alone are not sufficient.
